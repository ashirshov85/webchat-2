# Contract: Дизайн-токены «Aethergram»

**Branch**: `008-chat-window-styling` | **Нормативный источник**: [design/chats.html](../design/chats.html) (блок «1. БАЗА, ПЕРЕМЕННЫЕ И ПАТТЕРНЫ» и далее)

Единый источник визуальных констант всех поверхностей (FR-002). Реализация — `frontend/src/theme/tokens.css`; значения ниже — проекция прототипа, при расхождении побеждает прототип (FR-001). Этот файл не дублирует все ~400 строк CSS прототипа — фиксирует константы, на которые опираются контракты поведения и приёмка; полным эталоном остаётся сам прототип.

## 2. Шрифтовые роли (самохостинг, FR-003)

| Роль | Стек | Применение |
|---|---|---|
| body | `'Old Standard TT', 'Times New Roman', serif` (400/700 + italic) | основной текст, курсивные подписи, пункты меню, текст подтверждений |
| heading | `'Cormorant SC', Georgia, serif` (400/600/700) | заголовки, имена, бейджи, время в подписях, надписи кнопок (UPPERCASE + letter-spacing) |
| mono | `'Anonymous Pro', 'Courier New', monospace` (400/700 + italic) | поля ввода, текст сообщений, моно-значения (username/email) |

Требования: woff2 cyrillic+latin из npm-пакетов (самохостинг, внешний CDN запрещён); резервные стеки читаемы, layout не разрушается при недогрузке (edge case); кириллица+латиница в одном блоке — без подмены шрифта (SC-006).

## 3. Корпус-«машина» и паттерны (FR-004)

- `.machine`: max-width 1360px, `height: calc(100dvh - 36px)`, min-height 540px, радиус 18px, золотая окантовка (::before, inset 4px, border 2px, градиент по border-box с mask-composite), тени — по прототипу.
- Панели `.panel`: радиус 12px, `--panel-bg`, бордер `--gold-dark`, заклёпки — 4 radial-gradient-точки по углам (11px от края).
- Фоновые паттерны: `--pat-main` (шестерёнки 280×280) — фон body и сайдбара; `--pat-msg` (орнамент 240×240) — фон ленты сообщений; оба — статичные SVG data-URI.
- Зерно: `body::before` (fractalNoise SVG, opacity .55, z-50, pointer-events none); виньетка: `body::after` (radial-gradient, z-45). Скроллбары — золотые градиентные (webkit-стили прототипа).

## 4. Аватары (FR-024)

- Форма: круг (пользователи) 40px (заголовок 46px, лента 34px, подсказки 24–32px); октагон — `clip-path: polygon(30% 0,70% 0,100% 30%,100% 70%,70% 100%,30% 100%,0 70%,0 30%)` + `border-radius: 22%` (группы).
- Обод: `--gold-gradient`; внутренность: radial-gradient блик + `--av` (детерминированный цвет); инициалы — Cormorant SC 700 12px, цвет `#f5e8c8`, text-shadow.
- Палитра детерминированного цвета (`PALETTE`, из прототипа): `#c2622a`, `#7a5a8b`, `#4e7a8b`, `#5e8b7e`, `#8b3a3a`, `#a08830`; выбор: `PALETTE[fnv1a32(source) mod 6]`.
- Presence-точка 11px: online `#9dbb7d` + свечение + анимация `flick` 4s; offline `#6b5c39` тусклая без анимации; unknown — нейтральная (без ложного «офлайн»).

## 5. Пузыри и штампы (FR-018)

- Исходящие: фон `--gold-gradient`, текст `--ink`, `border-radius: 4px 12px 12px 12px`; входящие: `--input-bg`, текст `--cream`, `border-radius: 12px 4px 12px 12px`; max-width `min(72%, 560px)` (≤480px — 84%).
- Штампы: ✓/✓✓ SVG stroke, тёмные «гравированные» с белым ребром тиснения; анимация `tickStamp` .32s только при смене статуса.
- Появление пузыря: `pop` .32s cubic-bezier(.2,.9,.3,1.15); «пар» (3 puff'а) над композером при отправке.

## 6. Время и даты (FR-019)

- Время: ЧЧ:ММ (24ч, ru), Cormorant SC 10.5px, letter-spacing 1px, в ножке пузыря; время последнего сообщения в списке чатов — там же, c-top.
- Разделитель дат: длинный формат русской локали «19 сентября» (`day:'numeric', month:'long'`; год — при отличии от текущего), Old Standard TT italic 12.5px, `--muted`, линии-градиенты по бокам.

## 7. Радиусы, отступы, z-слои

- Радиусы: машина 18px / панель 12px / поля и кнопки 6–8px / меню и тосты 6–10px — по прототипу.
- Ключевые отступы: frame-body 12px gap; chat-head/input 12px 14–16px; список чатов — строки 9px 10px; лента 16px 18px 8px.
- Z-порядок: grain 50 → modal-back 47 → backdrop 35 → sidebar-drawer 40 → ctx-menu 55 / members-tip 56 → toast 99.

## 8. Анимации и reduced-motion (FR-004)

Анимации прототипа: `flick` (лампы/точки 4s), `pop` (пузырь), `tickStamp` (штамп), `puff` (пар), `srFlash`, переходы тоста/модали/drawer (.25–.3s). `prefers-reduced-motion: reduce` — глобально `animation-duration/transition-duration: .01s !important`, iteration-count 1 (паттерн прототипа); статичные паттерны/текстуры сохраняются, читаемость полная.

## 9. Адаптив (FR-029)

| Диапазон | Поведение |
|---|---|
| ≥901px | `html,body{overflow:hidden}` — машина целиком в окне, без прокрутки страницы; burger скрыт |
| ≤900px | burger (fixed 42px) + drawer: sidebar fixed `min(320px, 85vw)`, transform -120% ↔ 0 (.3s), backdrop; машина `margin-top 60px`, `height: calc(100dvh - 72px)` |
| ≤480px | кнопка «ОТПРАВИТЬ» компактна (letter-spacing 1px), пузырь до 84% ширины ленты |
| Клавиатура | `100dvh` + visualViewport-переменные: композер над клавиатурой, лента сжимается, прокрутки страницы нет |
