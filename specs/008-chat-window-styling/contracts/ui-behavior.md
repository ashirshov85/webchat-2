# Contract: Поведение UI-слоя «Aethergram»

**Branch**: `008-chat-window-styling` | API-контракты не меняются (SC-003) — этот контракт описывает интерфейс, который фича предъявляет пользователю

Визуальные константы — [design-tokens.md](./design-tokens.md). Ниже — поведенческие контракты новых/изменённых поверхностей (источник — спека + нормативный прототип). Реализация — `frontend/src/ui/` + перестроенные компоненты `chats/`/`groups/`.

## 1. Общие инварианты

- **Клавиатура (FR-035, SC-008)**: все интерактивы достижимы табуляцией, управление Enter/Space, Esc закрывает верхний слой; фокус видим (focus-ring в дизайн-системе); после закрытия меню/модали/drawer фокус возвращается на инициатор; в модалях и drawer — ловушка фокуса; меню — ArrowUp/Down.
- **Стекирование и Esc**: контекстное меню/подсказка → модаль → drawer → режим поиска сайдбара (сверху вниз).
- **Экранирование (FR-033)**: весь пользовательский текст — через React-текстовые узлы; `dangerouslySetInnerHTML` с пользовательскими данными запрещён.
- **Язык**: строки — русские, без i18n (Assumptions).
- **Тестовые хуки**: тексты статусов 004–007 («отправляется», «не отправлено», «Повторить», «Удалить», «доставлено», «прочитано») сохраняются (видимы или в aria-label) — SC-002.

## 2. Сайдбар

- **Список чатов (FR-008–010)**: элемент = аватар (+presence-точка direct) + имя + превью («Вы: » / «Имя: » / «Нет сообщений») + время последнего сообщения (ЧЧ:ММ; пусто без сообщений) + бейдж непрочитанных (кап «99+» при ≥100) + метка «заблокирован». Порядок — существующий (последнее событие DESC). Поиск фильтрует по имени чата (не по сообщениям).
- **Главное меню (FR-007)**: кнопка «три полоски» слева от поиска; пункты «Мой профиль», «Контакты», «Создать групповой чат»; закрытие: повторный клик, клик вне, Esc.
- **Табов «Чаты»/«Контакты» нет** (FR-006).

## 3. Модальная оболочка и формы

Единая оболочка (`ModalShell`): заголовок, тело-форма, встроенные ошибки, кнопки обычная/основная/опасная; закрытие по Esc и по фону (нажатие И отпускание на самом фоне — перетаскивание из окна не закрывает); подтверждение поверх открытой формы — переключением формы внутри одной оболочки, без второй подложки.

| Форма | Контракт |
|---|---|
| Контакты (FR-011–013) | Список: сортировка displayName → username (ru-locale); фильтр по подстроке имени/username/email без регистра; пустые состояния «Нет контактов» / «Ничего не найдено»; пометки «заблокирован», «чат удалён»; клик по контакту с чатом открывает чат; клик без чата — без действия. Меню «⋯»: Заблокировать/Разблокировать (подтверждение), Удалить чат (если есть) / Создать чат (если нет), Удалить контакт (подтверждение) — опасные пункты выделены |
| Добавить контакт (FR-012) | Точное совпадение username/email без регистра (№19 `searchUsers`); не найдено — ошибка «требуется точное совпадение», контакт не создаётся; найдено — подтверждение (имя, username · email) → контакт добавлен/переиспользован (идемпотентно, тост «Уже в контактах») → открытие переписки |
| Мой профиль (FR-015) | username, email — readonly; переключатель «Режим инкогнито» (№38): «Всем участникам вы отображаетесь как offline»; Сохранить → PUT → тост; редактирование имени — нет (008a) |
| Новый групповой чат (FR-023) | Название (валидация 006) + выбор участников из контактов (фильтр, пустые состояния); создание №27 → открытие чата, тост |
| Редактировать групповой чат (FR-023) | Название, описание, состав: добавление из контактов «+», удаление «✕» (валидация 006: ≥1 участник, title 1–64, description ≤256); PATCH №29 + №31/32; аватар группы пересчитывается при переименовании |
| Участники (FR-023) | Список с ролями; ростер-действия по иерархии 006 (kick/роль/передача владения — owner/admin); «Добавить в контакты» для собеседника вне контактов; «Вы» не выводится в списке (по прототипу) |
| Подтверждение (FR-014, SC-007) | Заголовок, текст с `<b>`-выделением имени, кнопки Отмена/действие; опасное действие — danger-кнопка; 100% деструктивных операций требуют подтверждения |

## 4. Окно чата

- **Заголовок (FR-016/017)**: аватар + имя + статус (direct: presence 007 — «В сети»/нейтральное «неизвестно», без ложного «офлайн»; group: «N участников» с плюрализацией) + единственная кнопка-«шестерёнка». Hover/focus статуса группы → members-tip: «Вы» первым (пометка «администратор» при владении), далее участники с пометками. Кнопки поиска (013) и звука (008a) не отображаются.
- **Меню «шестерёнки» (FR-023)**: direct — «Добавить в контакты» (если собеседник не в контактах), «Заблокировать/Разблокировать контакт» (подтверждение), «Удалить чат» (подтверждение); группа owner/admin — «Участники», «Редактировать чат», «Удалить чат»; member — «Участники», «Выйти из чата».
- **Лента (FR-018–020)**: пузыри по прототипу; аватары отправителей; имя отправителя в групповых входящих; время ЧЧ:ММ у каждого сообщения; разделители дат между днями (ровно один на стыке страниц); штампы ✓/✓✓ с анимацией при смене; outbox: «отправляется» (статично), «не отправлено» + Повторить/Удалить; пагинация вверх — существующая (анкер скролла).
- **Композер (FR-021/022, FR-030)**: золотая рама, кнопка «ОТПРАВИТЬ», Enter отправляет, фокус остаётся в поле (кнопка не забирает фокус на mousedown); лимит длины — валидация 004. Заблокированный контакт — поле и кнопка disabled, подсказка о блокировке (единственная блокировка ввода). Флуд-лимит/переполнение: ввод активен, сообщение встаёт в очередь («отправляется»), над полем — строка статуса «Повтор через N с» (головная retryAt-запись открытого чата, тикает один элемент); баннер переполнения очереди — по дизайн-системе.
- **Пустые состояния (FR-032)**: «Чат не выбран» после удаления открытого чата/выхода из группы (без автоперехода), «Нет сообщений», загрузка, ошибка — в едином стиле.

## 5. Тосты (FR-025)

Один слот, ~3000 мс, поверх всех слоёв; новый тост заменяет предыдущий; ровно один тост на завершённую операцию (успех или отклонение).

## 6. Звук (FR-028)

Только приём: короткий синтезированный «латунный звоночек» (WebAudio, без файлов). Реальное время — один сигнал на входящее событие любого чата (включая фоновые). Массовая доставка после разрыва — один сигнал на пакет. История/пагинация — без сигнала. Отправка — без сигнала (подтверждение визуальное). Запрет автозвука — молчаливый пропуск, функциональность не страдает. Настроек нет — всегда включён.

## 7. Адаптив (FR-029, SC-005)

≤900px — burger + drawer поверх контента с затемнением; закрытие: выбор чата, клик по затемнению, повторный burger. ≥901px — машина целиком в окне, прокрутки страницы нет, burger скрыт. Экранная клавиатура — композер виден над клавиатурой (visual viewport), прокрутки страницы нет. Список чатов достижим ≤2 действий.

## 8. Производительность (SC-010/SC-011)

60 fps прокрутки/анимаций ленты при 1000+ сообщений; 60 fps списка/поиска при 200+ чатах; первый рендер экрана чата ≤1 с; prefers-reduced-motion отключает все анимации без потери читаемости.

## 9. Что НЕ входит в контракт фичи

Typing-индикатор, lastSeen, отображаемые имена/alias, per-chat переключатель звука (008a); поиск по сообщениям, кнопка поиска в заголовке (013); ARIA/WCAG-контраст сверх клавиатурной навигации; i18n; изменение любых API-контрактов.
