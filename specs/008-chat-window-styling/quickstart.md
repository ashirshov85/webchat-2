# Quickstart: Валидация фичи «Стилизация окна чата»

**Branch**: `008-chat-window-styling` | Спека: [spec.md](./spec.md) | Контракты: [design-tokens](./contracts/design-tokens.md), [ui-behavior](./contracts/ui-behavior.md) | Модель: [data-model](./data-model.md)

## Предусловия

- Node ≥24, pnpm 12 (frontend/packageManager), backend webchat-2 запущен (или доступен стенд) для ручных сценариев
- Нормативный эталон: `specs/008-chat-window-styling/design/chats.html` (открывается в браузере напрямую — это утверждённый облик)

## Сборка и базовые проверки

```bash
cd frontend
pnpm install            # @fontsource/* (3 шрифта) + @playwright/test (dev)
pnpm lint               # eslint + prettier — без замечаний
pnpm typecheck          # tsc --noEmit — чисто
pnpm test               # Vitest: все тесты 004–007 (адаптированные локаторы) + новые ui/ — зелёные (SC-002, SC-004)
pnpm build              # dist собирается; в dist/assets — woff2 трёх шрифтов со своего origin (FR-003)
```

## Визуальная регрессия (SC-001)

```bash
pnpm exec playwright install chromium   # однократно
pnpm test:visual          # снимки ключевых экранов на fixture-данных (данные прототипа)
```

Ожидаемый результат: все ключевые экраны (список чатов; заголовок/лента/композер личного чата; групповой чат; модали «Контакты», «Мой профиль», создание/редактирование группы; контекстные меню; состояния outbox/синхронизации) проходят сравнение с эталонными снимками, произведёнными по прототипу, с допуском ≤ ~2% отличающихся пикселей; контрольные вьюпорты — эталонная desktop-ширина прототипа, открытый burger-drawer (~900px), окно чата ~480px. Расхождение > допуска — падение теста с diff-артефактом.

## Ручные end-to-end сценарии (SC-004, SC-005, SC-007–009)

Запуск: `pnpm dev` (+ backend), два браузера/профиля (или окна) для двух пользователей.

### A. Рескин и обмен сообщениями (US1)

1. Вход → сравнить облик с открытым рядом `design/chats.html`: корпус-«машина», окантовка, заклёпки, паттерны (шестерёнки/орнамент), зерно, виньетка, шрифты ролей (см. design-tokens §1–3).
2. Отправить сообщение (Enter и кнопкой «ОТПРАВИТЬ») → пузырь-«пластина», фокус остаётся в поле; входящее — «тёмная панель»; у исходящих штампы ✓ → ✓✓ (прочтение вторым пользователем) с анимацией штамповки.
3. ≥100 непрочитанных в чате → бейдж «99+».
4. Включить системно «уменьшить движение» → анимации отключены, читаемость сохранена.

### B. Навигация без табов (US2)

1. Кнопка меню у поиска → «Мой профиль» / «Контакты» / «Создать групповой чат»; повторный клик/клик вне/Esc закрывает.
2. «Контакты»: поиск по имени/username/email; добавление по точному username/email (совпадение → подтверждение → переписка; дубль → «Уже в контактах»; промах → ошибка).
3. Меню «⋯» контакта: блокировка (подтверждение) → композер неактивен с подсказкой; разблокировка → активен; «Удалить чат» (контакт остаётся, пометка «чат удалён») / «Создать чат»; «Удалить контакт» (чат остаётся).
4. «Мой профиль»: username/email readonly, инкогнито → сохранение → второй пользователь видит «офлайн»-семантику 007, тост подтверждения.

### C. UI-слой (US3)

Аватары с инициалами (пользователи — username, группы — название, октагон; цвет стабилен для одного имени, пересчёт при переименовании группы); presence-точки онлайн/офлайн/неизвестно; время ЧЧ:ММ у сообщений, разделители дат между днями; каждая операция — ровно один тост ~3 с; меню у края экрана смещаются в пределы экрана, Esc/клик-вне закрывают.

### D. Состояния устойчивости (US4)

1. Офлайн-отправка → «отправляется», сбой → «не отправлено» + Повторить/Удалить (повтор без дублей).
2. Переполнение очереди → баннер; флуд-лимит → строка «Повтор через N с» над композером, ввод активен.
3. Разрыв/восстановление связи → индикатор синхронизации, доставка без дублей и пропусков.
4. Длинная история → пагинация вверх, разделители дат на стыке страниц корректны.
5. Группа: шестерёнка → «Участники»/«Редактировать чат»/«Удалить» (owner-admin) или «Выйти» (member); после удаления открытого чата/выхода — «Чат не выбран».

### E. Мобильный drawer и звук (US5)

1. ≤900px: burger открывает drawer с затемнением; выбор чата закрывает; ≥901px — прокрутки страницы нет, burger скрыт.
2. Фокус в поле ввода на мобильном → композер над клавиатурой, прокрутки страницы нет.
3. Входящее в фоновый чат → один «звоночек»; массовая доставка после разрыва → один сигнал на пакет; история/пагинация — без сигнала; отправка — без звука; запрет автозвука до первого действия — пропуск без ошибок.
4. Прогнать A–D без мыши (только Tab/Enter/Space/Esc/стрелки) — вся функциональность доступна, фокус видим и возвращается на инициатор (SC-008).

## Браузерная матрица (FR-036, SC-009)

Последние 2 версии Chrome, Edge, Firefox, Safari (desktop + мобильные): повторить сценарии A–E — функциональность и облик идентичны; кириллица+латиница без «тофу» и подмены шрифта (SC-006).
