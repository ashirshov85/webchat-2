**Дата**: 2026-10-08 | Нормативный эталон облика: прототип `specs/008-chat-window-styling/design/chats.html` (FR-001 спеки). Дизайн-система, тосты, модали, контекстные меню, клавиатура — конвенции 008 без изменений.

## 1. Цепочка отображаемых имён (FR-001–FR-005)

**Разрешение** — единственная функция `resolveDisplayName(alias?, displayName?, username)`:

```text
alias (личный) → displayName профиля → username
```

| Поверхность | Источник данных | Что отображается |
|---|---|---|
| Список «Чаты» — peer личного чата | №12 peer (`displayName`,`alias`) | цепочка; инициалы — из цепочки, цвет — от `username` |
| Список «Чаты» — группа | title группы (006, без изменений) | — |
| «Контакты» — строки | №20 `ContactView` (`user.displayName`, `alias`) | цепочка |
| Участники групп (members-tip, №28) | `GroupMember.user` (`displayName`,`alias`) | цепочка |
| Поиск пользователей №19 | результат (`displayName`,`alias` если контакт) | цепочка (семантика поиска не меняется) |
| Заголовок личного чата | №11/№13 peer | цепочка (title + инициалы) |
| Typing-индикатор | данные участника (US1) | `{цепочка печатающего} печатает…` |
| «Мой профиль» / собственные поверхности | №10 + №39 | своё displayName; placeholder поля «Имя» = `username` |

- **Сортировка «Контактов»**: по цепочке (locale `ru` прототипа), затем `username` (текущая коллация) — FR-005.
- **Фильтр «Контактов»**: подстрока без регистра в `[цепочка, username, email]` — FR-005.
- **Аватары**: `initialsOf(отображаемое имя)`; цвет `colorOf(username)` — переименование не перекрашивает (FR-004).
- **Длинные имена**: усечение с многоточием, полный текст в tooltip (конвенция 008). Unicode — без «тофу» (008 SC-006). Совпадающие имена допустимы — различие через username в контексте.
- **Обновление у третьих лиц**: по рефетчу (открытие модалей/списков) — осознанное упрощение v1 (без realtime-события).

### 1.1 «Мой профиль» — поле «Имя» (FR-001)

- Модальная форма 008 + поле «Имя» (input, placeholder = `username`, максимум 64) над строкой инкогнито.
- Сохранение: `PUT /users/me/profile` (№39); пустое значение (в т.ч. только пробелы) = сброс к username **через явную очистку**; пробельно-непустое после trim — ошибка валидации `Укажите имя без пробелов в начале и конце` (инвариант 008-форм), прежнее значение сохраняется.
- Успех: тост `Профиль обновлён — {displayName || username}`; собственный displayName обновляется немедленно.
- Клавиатура/фокус — конвенции модалей 008 (FR-026).

### 1.2 «Переименовать» контакт (FR-003)

- Пункт **первым** в контекстном меню «⋯» контакта (перед «Заблокировать/Разблокировать»), открывает модальную форму (по образцу `#renameForm` прототипа): поле «Имя контакта», предзаполненное текущей цепочкой (alias, если задан).
- Сохранение: №40; пустое значение = **сброс alias** (возврат к displayName → username); пробельно-непустое — ошибка `Укажите имя контакта` (строка прототипа `chats.html:1648`).
- Успех: тост `Контакт переименован — {имя}` (прототип `:1655`); все поверхности владельца обновляются.
- Сброс отдельно: через ту же форму пустым значением (отдельной кнопки нет — YAGNI).

## 2. Typing-индикатор (FR-006–FR-009)

### 2.1 Отправка сигналов (композер)

| Событие ввода | Действие клиента |
|---|---|
| Первый символ после простоя | `POST /typing {start}` немедленно |
| Продолжение ввода | повтор `start` не чаще 3 с (окно повтора) |
| Отправка сообщения (любой исход, вкл. отклонённую пустую) | `POST /typing {stop}` |
| Очистка поля / удаление последнего символа в пустоту | `POST /typing {stop}` |
| Молчание 5 с при непустом поле | `POST /typing {stop}`; новый ввод — снова `start` |
| Композер заблокирован (008 FR-022: блок-пара, без чата) | сигналы не отправляются |

Сигналы привязаны к композеру конкретного чата; переключение чата = `stop` предыдущего (best-effort).

### 2.2 Отображение (TypingRow по прототипу)

- Позиция: последний элемент ленты сообщений открытого чата (`.msg.them` → `.bubble.typing-b`); единый экземпляр, скрыт при смене чата.
- Облик: три лампы-точки `.tlamp` (анимация `lampBlink` 1.2 с, задержки .2/.4 с, `--gold`), текст `.typing-txt` курсивом `Old Standard TT`.
- Текст:
  - 1 печатающий: `{имя} печатает…` (имя — цепочка US1; в группе — конкретного участника, его аватар-инициалы/цвет рядом);
  - N > 1: `{имя первого} и ещё {N-1} печатают…` (агрегация FR-008).
- Появление ≤ 2 с после `typing.started`; исчезновение: `typing.stopped` / `message.created` от печатающего / 10 с без продления (страховка).
- Свой набор (даже с других своих устройств) не отображается никогда (сервер не адресует отправителю).
- prefers-reduced-motion: лампы без анимации (конвенция 008 FR-004).

## 3. lastSeen (FR-010–FR-011)

| Статус | Отображение |
|---|---|
| online | `В сети` (007, без изменений) |
| offline + `lastSeenAt` есть | `Был в сети — {время}` (формат §3.1) |
| offline без `lastSeenAt` (нет данных/скрыто) | `Был в сети — давно` |
| unknown | пустая строка статуса (007, без ложного «офлайн») |

- **Места**: заголовок личного чата (`.status-txt`) и превью строк «Контактов» (`.c-prev`, если нет флагов «заблокирован/чат удалён»). В сайдбар-списке чатов текст статуса не показывается (только точка — прототип).
- **Формат §3.1** (`lastSeenFormat`, локаль ru-RU, пояс наблюдателя): сегодня → `HH:MM`; иначе → `D месяца, HH:MM` (`24 сентября, 16:20`); другой год → `D месяца YYYY, HH:MM`. Фолбэк — `давно`.
- Данные: №36-снапшот и `presence.updated` (поле `lastSeenAt`, [realtime-events.md §2.1](./realtime-events.md)); merge в presenceStore — по строго большему `rev`, как 007.

## 4. Переключатель звука чата — кнопка-«звонок» (FR-012–FR-015)

### 4.1 Кнопка

- Заголовок чата, `.ch-btns` **между** местом поиска (013, не отображается) и шестернёнкой — SVG-колокол прототипа (`chats.html:446`).
- Состояния: `вкл` (умолчание) — полный вид; `выкл` — класс `.off {opacity:.45}` (прототип `:221`).
- Доступность: `title="Звуковые оповещения"`, `aria-pressed={вкл}` (первое применение в проекте), focus-visible — конвенция 008 FR-035.
- Действие: `PUT /chats/{chatId}/sound` (№42) с текущим состоянием кнопки; успех — локальное переключение + тост `Звуковые оповещения включены/отключены — {имя чата по цепочке}` + звук отклика (§4.2); ошибка сети/429 — тост ошибки, состояние не меняется (офлайн-очереди нет).
- Мультидевайс: `chat.sound.updated` из собственного канала обновляет кнопку/поведение ≤ 2 с (SC-006); (ре)подключение — состояние из №12/№13.

### 4.2 Звуки (расширение `ui/sound.ts`)

| Сигнал | Когда | Звук |
|---|---|---|
| Отклик «вкл» | переключение кнопкой | «динь-динь» 1050/1400 Гц (существующий `playBellTone`) |
| Отклик «выкл» | переключение кнопкой | «глухой щелчок» 300 Гц (`bellTone(300,t,.3,.05)` прототипа `:779`) — новый |
| Приём (realtime) | входящее `message.created` чужое | звонок **только если** чат не приглушён (`soundEnabled !== false`) |
| Приём (sync-батч 005) | пакет после разрыва | звонок **только если** среди пришедших есть неприглушённые чаты (per-chat подсчёт) |

- Отправка своих сообщений не звучит; коалесцирование 008 FR-028 сохраняется; запрет автозвука браузером — молчаливый пропуск, состояние настройки не меняется (edge-кейс).
- Визуальные уведомления (бейджи, лента, тосты) не фильтруются настройкой (FR-014).
- Приглушение действует на все устройства пользователя (серверное значение).

## 5. Тексты (нормативные строки, паритет прототипа/008)

```text
'{имя} печатает…' / '{имя} и ещё {n} печатают…'
'В сети' | 'Был в сети — {время}' | 'Был в сети — давно'
'Звуковые оповещения включены — {имя}' | 'Звуковые оповещения отключены — {имя}'
'Контакт переименован — {имя}' | 'Укажите имя контакта'
'Профиль обновлён — {имя|username}'
'Переименовать' (пункт меню) | 'Имя' (лейбл профиля) | 'Имя контакта' (лейбл формы)
```

Экранирование пользовательских имён — React-инвариант (008 FR-033); `dangerouslySetInnerHTML` не вводится.
